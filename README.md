# ✨ Rutina de Ejercicios

Es una aplicación web para organizar y seguir una rutina semanal de ejercicios de forma simple, visual y motivadora.

La interfaz está inspirada en una estética mágica en tonos lilas y rosados, con elementos decorativos y animaciones.

## 💜 Funciones

- Organización semanal de entrenamientos
- Detección automática del día actual
- Destaca la rutina correspondiente con `✦ HOY`
- Botón para abrir directamente el video de entrenamiento
- Marcar rutinas como completadas
- Barra de progreso semanal
- Sistema de estrellas
- Persistencia de datos con `localStorage`
- Diseño responsive para computador y celular
- Animaciones y efectos visuales
- Efecto de brillitos al presionar imágenes
- Sonido mágico al interactuar con algunos elementos
- Soporte PWA para instalar la página como aplicación

## 🗓️ Rutina semanal

| Día | Entrenamiento |
|---|---|
| Martes | Brazos + espalda + abdomen |
| Jueves | Brazos |
| Viernes | Glúteos |
| Domingo | Full Body + abdomen |
